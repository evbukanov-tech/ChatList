Возможности

Параллельные запросы

Один промт уходит во все активные модели одновременно через OpenRouter.

Сравнение ответов

Результаты в таблице с чекбоксами — сохраняйте только нужные строки.

История и экспорт

Промты и ответы в SQLite, выгрузка в Markdown и JSON.

AI-ассистент промта

Улучшение и переформулировка запроса перед отправкой.

Управление моделями

Добавляйте, включайте и отключайте модели без правки кода.

Локальные данные

API-ключи в .env.local на вашем компьютере, не в облаке.

Быстрый старт

  1. Скачайте установщик — кнопка «Скачать для Windows» выше.
  2. Установите ChatList — мастер Inno Setup, права пользователя достаточно.
  3. Укажите API-ключ — скопируйте _internal\.env.example в _internal\.env.local и добавьте OPENROUTER_API_KEY.
  4. Отправьте промт — выберите модели, сравните ответы, сохраните лучшие.

Системные требования

  • Windows 10/11 (64-bit)
  • ~150 МБ на диске после установки
  • Ключ OpenRouter (openrouter.ai)
  • Подключение к интернету для запросов к API
