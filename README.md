# ChatList

Python-приложение для отправки одного промта в несколько нейросетей и сравнения ответов.

## Требования

- Python 3.11+
- PyQt6, httpx, python-dotenv

## Установка

```powershell
cd C:\Work\ChatList
pip install -r requirements.txt
```

## Настройка API-ключей

1. Скопируйте шаблон:

```powershell
Copy-Item .env.example .env.local
```

2. Укажите ключ OpenRouter в `.env.local`:

```env
OPENROUTER_API_KEY=sk-or-v1-ваш-ключ
```

Файл `.env.local` имеет приоритет над `.env` и не попадает в git.

При первом запуске в базу добавляются примеры моделей OpenRouter (`openai/gpt-4o-mini`, `google/gemini-2.0-flash-001` и др.). Имя модели в таблице `models` совпадает с идентификатором на OpenRouter.

## Запуск

```powershell
python main.py
```

## Интерфейс

| Вкладка | Назначение |
|---------|------------|
| **Запрос** | Ввод промта, отправка в активные модели, просмотр ответов, сохранение выбранных |
| **Модели** | CRUD нейросетей, включение/отключение (`is_active`) |
| **Промты** | История сохранённых промтов, поиск и сортировка |
| **Результаты** | Сохранённые ответы из БД |
| **Настройки** | Таймаут запросов, заголовки OpenRouter |

### Рабочий процесс

1. Введите промт или выберите из истории.
2. Нажмите **Отправить** — запрос уйдёт во все активные модели параллельно.
3. Отметьте нужные ответы чекбоксами.
4. Нажмите **Сохранить** — выбранные строки попадут в SQLite.
5. **Экспорт Markdown / JSON** — выгрузка отмеченных результатов в файл.

## Структура проекта

```
db.py           — SQLite
models.py       — логика моделей
network.py      — HTTP-запросы к API
session.py      — временная таблица результатов в памяти
config.py       — .env / .env.local
seed.py         — начальные данные
main.py         — GUI
export_utils.py — экспорт
```

Логи запросов: `logs/chatlist.log`
